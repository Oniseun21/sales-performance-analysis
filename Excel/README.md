# Excel Data Cleaning

## Project Overview
Microsoft Excel was used to clean and prepare the raw sales dataset for analysis.

## Data Cleaning Operations

1. Removed duplicate records to improve data consistency.
2. Replaced missing values with "Nil".
3. Corrected data types to ensure accurate data representation.
4. Standardised date formats for accurate time-based analysis.

## Project Files
- sales_data_raw.xlsx: Original sales dataset.
- sales_data_cleaned.xlsx: Cleaned dataset ready for analysis.

## Tools Used
- Microsoft Excel
